D'PIMENTAS – Sistema de Gerenciamento de Restaurante

1. Apresentação do Projeto

O projeto D'Pimentas consiste no desenvolvimento de um site e sistema de gerenciamento para um restaurante, com o objetivo de melhorar a organização dos processos internos e facilitar o atendimento aos clientes.

A proposta busca oferecer soluções tecnológicas para auxiliar nas atividades do estabelecimento, incluindo o gerenciamento de funcionários, clientes, produtos, cardápio, pedidos, entregas e contratos.

O projeto foi desenvolvido como atividade acadêmica, envolvendo conhecimentos de desenvolvimento Web, programação em Java, banco de dados e Engenharia de Software.

2. Objetivo do Projeto

Desenvolver uma solução informatizada para auxiliar na administração do restaurante D'Pimentas, tornando os processos mais organizados, práticos e eficientes.

O sistema busca contribuir para a organização das informações, o controle dos pedidos e a melhoria das atividades realizadas pelos funcionários.

3. Tecnologias Utilizadas

- HTML: estruturação das páginas do site.
- CSS: estilização e organização das interfaces gráficas.
- Java: desenvolvimento das classes e funcionalidades do sistema.
- SQL: criação, organização, consulta e manipulação dos dados.
- Microsoft SQL Server: gerenciamento do banco de dados relacional.
- SQL Server Management Studio (SSMS): criação e execução dos scripts SQL.
- Visual Studio Code: ambiente utilizado no desenvolvimento do site e do código Java.

4. Estrutura do Projeto

O repositório está organizado em três partes principais:

4.1 Desenvolvimento Web – HTML e CSS

Responsável pela criação e estilização das interfaces gráficas do restaurante D'Pimentas, incluindo páginas de apresentação, cardápio, delivery e demais funcionalidades visuais do site.

4.2 Desenvolvimento Back-End – Java

Responsável pela implementação das classes e funcionalidades do sistema, organizadas em pacotes, contemplando áreas como administração, cardápio, localização, pedidos, pessoas e utilitários.

4.3 Banco de Dados – SQL

Responsável pela modelagem, estruturação e alimentação do banco de dados relacional, utilizando scripts SQL para criação e inserção de informações nas tabelas do sistema.

5. Organização dos Arquivos no GitHub

O projeto está dividido nas seguintes pastas:

- site d pimentas: arquivos HTML, CSS, imagens e demais recursos utilizados no site.
- java d pimentas: código-fonte Java, classes e pacotes do sistema.

7. Conclusão

O desenvolvimento do projeto D'Pimentas surgiu da necessidade de melhorar a organização e o gerenciamento das atividades de um restaurante. A utilização de processos manuais pode ocasionar erros nos pedidos, dificuldades na comunicação entre os funcionários e falta de controle sobre o andamento das atividades.

Durante o trabalho, foram identificadas as principais necessidades do estabelecimento e desenvolvidas propostas para atendê-las. Foram elaboradas documentações, protótipos e interfaces gráficas, além de funcionalidades voltadas ao cadastro de funcionários, gerenciamento do cardápio, registro e acompanhamento de pedidos.

Para o desenvolvimento, foi escolhido o modelo Cascata, que organiza o projeto em etapas sequenciais. O trabalho envolveu o levantamento de requisitos, o planejamento, a elaboração dos protótipos, a codificação e os testes das funcionalidades, permitindo aplicar os conhecimentos adquiridos ao longo do semestre.

Diante disso, compreende-se que o desenvolvimento de um sistema para o restaurante D'Pimentas pode contribuir para melhorar a organização de seus processos. Assim, o projeto buscou responder à seguinte questão: como a tecnologia pode auxiliar na gestão de um restaurante? Por meio das funcionalidades propostas, foi possível apresentar uma solução que busca tornar as atividades mais práticas, organizadas e eficientes, além de proporcionar à equipe uma experiência de planejamento e desenvolvimento de software.
